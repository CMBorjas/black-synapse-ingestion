# Session Notes — 2026-05-06

## Storage Migration: Qdrant → Postgres (pgvector)

Qdrant was removed from the stack. All vector storage now lives in Postgres using the `pgvector` extension.

**New tables:**
- `document_chunks` — one row per ~500-token chunk, with a `vector(768)` embedding column and an HNSW index for cosine similarity search
- `chat_memory` — same structure for consolidated chat session embeddings

**Removed:**
- `qdrant-client` dependency from `worker/requirements.txt`
- All `QdrantClient`, `PointStruct`, `VectorParams` usage from `pipeline.py`

---

## Embeddings: OpenAI → Ollama (nomic-embed-text)

No OpenAI API key is required for ingestion. Embeddings are generated locally via Ollama.

- Model: `nomic-embed-text` (274 MB, 768 dimensions)
- Pulled with: `ollama pull nomic-embed-text`
- `get_embedding()` in `utils.py` now calls `POST /api/embed` on the local Ollama instance
- `OPENAI_API_KEY` is now optional — only needed if GPT-4o Vision is used for PDF image descriptions

**worker/.env** updated:
```
EMBEDDING_MODEL=nomic-embed-text
EMBEDDING_DIM=768
OLLAMA_URL=http://localhost:11434
```

## PDF Ingestion via the App

The `lynx-server` container forwards uploaded PDFs to the ingestion worker via `POST /ingest/pdf`.

**Fix applied:** `WORKER_URL` was defaulting to `http://localhost:8000` inside Docker, which resolves to the container itself — not the host. Added to `black-synapse-app/.env`:
```
WORKER_URL=http://host.docker.internal:8000
```

Tested end-to-end: uploaded `Ridwan_Resume.pdf` → 2 chunks, embeddings stored, `has_embedding: true` on both.

## Debug Endpoints Added

Two new read-only endpoints on the worker for visibility into the pipeline:

**`GET /debug/ingest?limit=20`**
Returns total document/chunk counts and recent ingestion log entries (event type, timestamp, source, title).

**`GET /debug/chunks/{doc_id}`**
Returns every chunk for a document: index, character count, 200-char text preview, and whether an embedding was saved.

## Microsoft OAuth Fix

Connecting Microsoft was failing with HTTP 400 from n8n's credential API. Two issues:

1. `graphApiBaseUrl` — removed from n8n's `microsoftOutlookOAuth2Api` schema in a newer version. Removed from `buildCredentialData`.
2. `userPrincipalName` — now required by n8n's schema. Fixed by calling `GET https://graph.microsoft.com/v1.0/me` immediately after token exchange and passing the UPN into the credential payload.

Added `afterTokenExchange` hook pattern to `oauthProviders.js` so provider-specific post-token enrichment stays self-contained.

## Worker Setup

The FastAPI worker runs on the host (not in Docker) at port 8000.

Start it with:
```bash
cd /home/blacksynapse/black-synapse-ingestion
PYTHONPATH=/home/blacksynapse/black-synapse-ingestion \
  uvicorn worker.app.main:app --host 0.0.0.0 --port 8000
```

Config lives in `worker/.env`. Postgres URL points to the compose stack on port 5433.
